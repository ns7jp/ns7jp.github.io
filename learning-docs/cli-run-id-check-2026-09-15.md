## 案内した検査コード

以下は会話で案内したコードです。保存操作と動作結果を画面で確認しましたが、本人のローカル原本の取得・ハッシュ照合は行っていません。

```bash
#!/usr/bin/env bash

if [ "$#" -ne 1 ]; then
  echo "使い方：bash check-run-ids.sh ログファイル" >&2
  exit 2
fi

awk '
  $1 == "START" || $1 == "END" {
    if ($2 !~ /^run_id=[A-Za-z0-9-]+$/) {
      print "形式不正：行" NR
      bad=1
      next
    }
    id=substr($2, 8)
    seen[id]=1
    if ($1 == "START") starts[id]++
    else ends[id]++
  }
  END {
    for (id in seen) {
      printf "ID=%s START=%d END=%d\n", id, starts[id], ends[id]
      if (starts[id] != 1 || ends[id] != 1) bad=1
      count++
    }
    if (bad) exit 1
    if (count == 0) {
      print "判定保留：実行IDの記録なし"
      exit 3
    }
  }
' < "$1"
```

START・ENDの第2フィールドからIDを取り出し、IDごとに件数を数えます。表示順は問いません。人工サンプルはSTART Aのみ、またはSTART AとEND Aを2行という構成です。code=0は人工入力でありHTTP成功の証拠ではありません。
