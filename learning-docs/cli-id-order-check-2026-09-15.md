## 修正前の問題と追加処理

元のスクリプトを残して別名へコピーする手順で編集しました。コピーの終了コードは提示画像では未確認です。元の件数加算を次の処理に置き換えました。

```awk
    if ($1 == "START") {
      starts[id]++
    } else {
      if (starts[id] == 0) {
        print "順序不正：行" NR " ID=" id " のSTARTより前にEND"
        bad=1
      }
      ends[id]++
    }
```

同じIDのSTARTをまだ読んでいない状態でENDが現れた場合、badを設定します。既存のEND処理はbadがあれば終了コード1を返します。コードは案内と差分画面に基づき、ローカル原本の取得・ハッシュ照合は行っていません。
