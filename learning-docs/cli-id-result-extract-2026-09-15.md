# 検査合格後にIDと結果を抽出

実施日：2026年9月15日（JST）

本人がWSL Ubuntuの端末で、ログ検査に合格した場合だけEND行から実行IDと終了コードを抽出する条件分岐を実行しました。AIが手順を案内し、本人提示の端末画像を読み取って公開用要約を作成しています。AIの代理実行やCIの実測ではありません。

[終了コード検査付き版の実ログ適用](./cli-id-code-history-2026-09-15.md)に続く演習です。正常入力は保存済みHTTP実行ログ、不正入力は今回作成した人工サンプルです。新しいHTTP接続は行っていません。

## 本人が確認した結果

| 入力 | 検査・抽出の結果 |
| --- | --- |
| 保存済みHTTP実行ログ | 各IDのSTART=1 END=1を確認後、END行のrun_idとcodeを2行抽出。抽出終了コード0 |
| ENDにcodeがない人工入力 | 行2の終了コード形式不正、検査1。「検査不合格のため抽出しません」を表示し、抽出へ進まなかった |

正常入力から取り出したcodeは過去の0と22です。今回の抽出0はawkの抽出成功で、記録されたHTTP処理がすべて成功したという意味ではありません。対象スクリプト・ログの検索は各1件、両検索の終了コード0でした。

端末上で実行した分岐の形は次のとおりです。各変数は事前に確認したファイルを指します。

```bash
if bash "$code_checker" "$id_log"
then
  awk '$1 == "END" { print $2, $3 }' "$id_log"
  echo "結果抽出の終了コード=$?"
else
  validation_status=$?
  echo "検査不合格のため抽出しません：終了コード=$validation_status"
fi
```

人工入力はSTART run_id=AとEND run_id=Aの2行です。正常入力と同じ分岐へ渡しましたが、検査が失敗したためelse側が実行されました。人工サンプル作成の個別終了コードは採取していません。
