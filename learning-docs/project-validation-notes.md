## 実際に確認できたこと（記録時点）

- GitHubの自動テスト（一時的なUbuntu環境）で設定を2回実行し、2回目に不要な変更が出ないことを確認しました。この記録の条件での結果です。
- 同じ自動テストで、監視用の10個のサービスと、通知を受け取るテスト用の1個（計11個）を起動し、異常と復旧の通知、ログの受け取りを確認。
- 停止させたサービスの自動復旧と、監視データをバックアップから戻せることを確認。
- 前の版への切り戻しはGitHubの自動テストで確認。ディスク拡張、データベース復元、通信障害の調査の演習は、AI支援セッションがAI側の作業環境で実行した記録です（同じ演習は、本人の環境ではまだ行っていません）。
- 実行して初めて見つかった問題を欠陥台帳に記録しています（2026年10月時点で49件。うち、誤って合格と判定していたもの10件）。AI支援セッションや自動テストの実行で見つかったものが多く、手元の仮想マシンでの作業で見つかったものも含みます。
