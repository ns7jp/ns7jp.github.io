Reproduce the Checks

CI で実行する主要コマンド

node scripts/check-static-links.js
Invoke-Pester -Path support-scripts/tests
docker compose -f monitoring-stack/docker-compose.yml config --quiet
ansible-playbook -i ansible/inventory.ini ansible/playbook.yml --syntax-check
terraform -chdir=cloud-lab/terraform test
shellcheck support-scripts/linux-triage.sh

読み方

  • CI の合格は、公開成果物が再現可能な検証対象になっている証拠です。
  • Terraform は mock provider による plan テストで、世界公開 SSH を拒否する入力検証も確認します。
  • 本番の通知、秘密管理、バックアップ復旧は Production Readiness に分離しています。
  • 障害対応の流れは Incident Drill で確認できます。
