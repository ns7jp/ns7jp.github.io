## 終了コードとHTTPステータスの読み分け

今回のcurlには--failを付けていません。終了コード0はHTTP応答を正常に受信したことを示しますが、目的のページが存在することは示しません。受信したHTTPステータスは404で、本文も404 Not Foundでした。

[nginx停止演習](./cli-recovery-2026-09-14.md)の接続失敗とは区別します。

| 確認対象 | 実際の結果 | 読み取れること |
| --- | --- | --- |
| 今回の存在しないページ | HTTP 404、curl 0、404本文 | サーバーは応答したが要求したページは見つからない |
| 過去の意図的なサービス停止 | HTTP応答なし（curl表示000）、curl 7 | TCP接続できず、HTTP応答を受け取れない |

上記の停止は過去の演習結果で、今回サービスを止めて再検証したわけではありません。HTTP 404を、サーバー全体の停止や通信失敗と同一視しません。
