設計上の判断
─────────
1. パブリック IP は Bastion のみ。VM 直接公開しない（攻撃面最小化）
2. NSG は implicit deny に頼らず明示拒否ルールを priority 4000 で配置
3. オンプレ Ansible Playbook の対象 (Ubuntu 22.04) と OS を一致させ、再利用可能
4. オンプレ AD と Entra ID は Entra Connect で片方向同期
5. リソースタグ env=lab / owner / purpose を全リソースに付与（コスト棚卸し用）
