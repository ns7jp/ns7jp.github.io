AWS VPC / Terraform Scenario

オンプレの VLAN / ACL とクラウドの VPC / SG を対応づけるLab

クラウド運用の入口として、AWS VPC、Public / Private Subnet、Route Table、Security Group を最小構成で整理しました。Terraform は構文検証までを CI に乗せ、課金インパクトが出やすい EC2 / NAT Gateway / Elastic IP は初期構成から外しています。

Change / Verify / Cost Guardrail

変更前確認

  • terraform fmt -check で書式を揃える。
  • terraform init -backend=false で provider 取得と初期化を検証。
  • terraform validate で構文と参照関係を確認。

セキュリティ

  • SSH は admin_cidr のみに限定し、0.0.0.0/0 を禁止。
  • Private 側は Bastion SG からの SSH / node_exporter のみ許可。
  • 本番では SSM Session Manager / VPN / Zero Trust Access を優先。

コスト

  • 初期構成では EC2 / NAT Gateway / Elastic IP を作らない。
  • 追加する場合は Budget Alert と削除手順を先に用意する。
  • 検証目的のリソースには Project / Environment タグを必須化。

本番化差分

  • CloudTrail、VPC Flow Logs、GuardDuty、Security Hub を追加。
  • CloudWatch Alarm と通知先を Runbook に紐づける。
  • AWS Backup とリストアテストを月次運用に入れる。
