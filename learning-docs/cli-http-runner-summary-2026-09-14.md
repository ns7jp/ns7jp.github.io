## 失敗件数と内訳を分ける

対象ログの3記録は以前のHTTP試験で作成したもので、内訳は次のとおりです。

| 過去の試験 | 記録された確認処理の終了コード |
| --- | --- |
| HTTP 200・期待する文字列あり | 0 |
| HTTP 200・期待する文字列なし | 1 |
| 存在しないURLでHTTP 404 | 22 |

集計スクリプトは0以外の記録をまとめて失敗として数えるため、失敗件数は2になります。件数だけで両方を404とは判断しません。この内訳は以前に提示された元ログの内容に基づき、今回の集計スクリプトが原因別に分類して表示した結果ではありません。

集計処理が返した1は失敗記録ありの判定であり、元ログの各終了コード1・22や、形式検査不合格の4とは役割が異なります。
