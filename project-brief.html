構成と学習の流れ

Request

ブラウザ → Nginx → app

Ubuntu上でDocker Composeを使って起動し、HTTP応答と認証を確認します。

Metrics / Logs

数値とログをGrafanaで見る

Prometheusが数値を取得し、AlloyがLokiへログを送ります。Grafanaから両方を参照します。

Practice

構築 → 確認 → 復旧

期待値と実結果を記録し、異常時の確認・復旧・引き継ぎまでを学びます。

結果と確認範囲

本人のVM操作では初期設定・監視・部分的な復旧を確認しました。2026年8月のCIでは一時Ubuntu環境で23項目がPASS。CIやAI実行の結果を、本人の独力技能や本番運用の実績には数えません。

長期稼働、実Slack通知、AWS環境の作成・削除、別サーバーへの復元は未完了です。検証証跡台帳で日付・実行者・判定を確認できます。
