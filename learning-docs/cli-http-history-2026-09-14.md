## 追記の仕組み

見出しと日時も含めて>>を使用しました。>は既存ファイルの内容を切り詰めて書き込みますが、>>は既存内容の後ろに追加します。スクリプト実行には次の形を使い、エラーメッセージも同じログへ保存しました。

```bash
bash "$body_script" "$url" >> "$history_dir/history.log" 2>&1
run_status=$?
printf 'スクリプト終了コード=%s\n' "$run_status" >> "$history_dir/history.log"
```

これは構造を説明する抜粋で、各変数の準備は省略しています。処理結果22と、ログ追記・表示の成功0は別の結果です。今回のログは実行ごとの要約・一致行・メッセージであり、完全なHTTP応答本文を保存したものではありません。
